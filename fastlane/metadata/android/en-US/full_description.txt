Telos Launcher is a privacy-first, fully open-source (GPLv3) Android launcher built with Kotlin and Jetpack Compose.

Features include:
• Powerful Unified Search (contacts, files, apps, calculations)
• Virtual Apps System and Workspace Profiles
• Native Shizuku automation for system-level anti-kill protection, advanced background suspension, and true root-less control.
• Memory-optimized architecture with automated DEX AOT Compilation.
• Deep F-Droid compliance and reproducible build pipeline.
