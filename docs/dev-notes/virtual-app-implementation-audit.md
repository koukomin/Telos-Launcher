# Virtual-app implementation audit — 19 October 2026

This is a source audit, not a physical-device certification. Git records commit authors; they do not prove which AI tool produced a change. Findings below must not be attributed to Gemini without the original development transcript.

| Area | Verified finding | Current action |
| --- | --- | --- |
| Akou | The old listening path only delayed 3.5 seconds. It never started AudioRecord. A GET to a sample endpoint fell back to a fabricated “Telos Acoustic Melody / Telos Artists” success result. | Removed the sample network call, invented result, pretend listening and microphone prompt. A real 16 kHz PCM capture → local Audile/SongRec fingerprint → Shazam match path now replaces it, with no API key or raw audio upload. CI includes upstream golden-signature fixtures. |
| Clock alarms on main | Alarms were a remembered Compose list with no AlarmManager scheduling or durable storage. Audio selection did not provide an actual file/radio picker. | PR #41 adds persisted one-shot scheduling, boot restoration, real sound selection and a playback service. Hardware/permission behavior still needs device validation. |
| Ermis | The repository documented an IMAP/SMTP client but contained no native mailbox engine or route. | Replaced by native IMAP/SMTP with verified TLS, encrypted credentials/cache, actual MIME attachments, optional authenticator consent and Message-ID conversation grouping. |
| Camera | Camera dependencies and mode UI existed, but capture launched another camera app. Documentation described engines that were absent. | Replaced by native CameraX/Camera2 capture, hardware-gated controls, RAW/JPEG, bounded panorama and explicit foreground LAN webcam. Vendor branding removed. |
| Terminal | No executable embedded Termux runtime. The current implementation downloads/installs/opens official Termux. | Treat as an external companion, never claim embedded compatibility. |
| System processes | Running process names/PIDs come from ActivityManager, with Android visibility restrictions, but per-process memory had been hardcoded to zero. | Reads actual per-process PSS via ActivityManager where Android permits; inaccessible/zero-denied memory remains an explicit unknown dash. CPU is unknown until two valid /proc/stat samples exist, or whenever reading fails. Parsing counts iowait as idle and does not double-count guest time. Unit tests cover unavailable/reset counters. |
| Messages legacy repository | MessageRepositoryImpl emits an empty list, but the current Messages UI does not consume it. | The active screen uses SmsThreads/SmsStore and Android Telephony providers. Removed the unused always-empty implementation and its Koin binding; retained the unbound legacy interface with accurate documentation. |
| Magnifier / Flashlight | Magnifier opens Camera2, changes real zoom/torch and stops repeating for freeze. Flashlight calls setTorchMode and generates actual audio patterns. | Fixed magnifier filters that previously emitted solid yellow/white: they now preserve luminance contrast with distinct yellow/black and blue/yellow matrices. Zoom uses reported hardware bounds and supports sensor-crop fallback before API 30; unavailable torch/zoom/freeze controls are disabled. Camera closes on pause and reopens on resume. Flashlight stops torch/audio/strobe/Morse on background/disposal, preserves original window brightness and no longer clamps Android's restore-brightness sentinel to 1%. Unit tests cover filter contrast; physical camera/torch testing still required. |
| Radio / TV / Video / YouTube / Stremio | Source and service paths connect actual providers, catalogs, parsers and media playback. | Not certified end-to-end by this source inspection; failures and incomplete features are not proof of fake data. |

Scope: virtual routes/catalog, suspicious constants and simulated delays, active repository wiring, prior Clock implementation, Akou recognition path, system telemetry and camera/tool entry points. Further review must follow UI actions into their underlying service rather than classify by comments or a grep match alone.

Additional source review: Calculator evaluates expressions/converters, Calendar queries the Android calendar provider, Voice Recorder uses MediaRecorder, and SIP/Radio paths invoke actual native/network engines. No additional synthetic-success path was found in these reviewed routes. These observations do not certify hardware/network behavior.
