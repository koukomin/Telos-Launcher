# Version 2.4.0

::: info Kvaesitso version
**Version 1.41.0** (July 2026)
:::

## New plugin types

Two new plugin types have been added. Both are purely additive - existing plugins are
unaffected.

### Gesture actions

Plugins can now expose named actions that users can bind to a launcher gesture (swipe, double
tap, etc.) from Settings > Gestures. See
[Gesture Action Provider](/docs/developer-guide/plugins/plugin-types/gesture-action.html).

### Widgets

Plugins can now supply a short list of title/subtitle/value rows to be shown as a home screen
widget. This is data-only - the launcher renders the widget, the plugin only supplies content.
See [Widget Provider](/docs/developer-guide/plugins/plugin-types/widget.html).
