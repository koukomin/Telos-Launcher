# Ermis

Ermis is a webmail hub. Choose Gmail, Outlook, Yahoo or Proton, or enter a custom HTTPS webmail address. The selected provider opens through Telos Web Apps; account sign-in and mailbox functionality belong to that provider.

Ermis does not currently implement native IMAP/SMTP synchronization, background mail notifications or a local mail database. Launcher settings are no longer used as the fallback destination for this virtual app.
