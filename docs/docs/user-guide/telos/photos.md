# Telos Photos

A gallery, photo editor and document viewer with a privacy focus.

## Gallery

- Albums by folder, and a date timeline.
- Full screen viewer with pinch zoom.
- Also opens images from other apps.

## Metadata (EXIF)

| Action | Details |
| --- | --- |
| View | Camera, date, location and more |
| Edit | Change fields |
| Remove location | Keeps the rest |
| Remove all metadata | Clean file |
| Share without metadata | Sends a stripped copy |

::: tip
Use "share without metadata" before posting photos publicly, since the location can reveal where you live.
:::

## Editor

Rotate, flip, crop ratios, brightness, contrast, saturation and filters. The editor **saves a copy**, so
your original stays untouched.

## Document viewer

Telos Photos also opens documents.

| Format | How it is shown |
| --- | --- |
| PDF | Page by page with zoom |
| Plain text and code | Editable, saved back to the file |
| Word (.docx) | Extracted text and tables |
| Excel (.xlsx) | Extracted text and tables |
| PowerPoint (.pptx) | Extracted text |
| OpenDocument | Extracted text and tables |
| RTF | Extracted text |
| EPUB | Readable text |

::: warning Limitations
Office and OpenDocument files are shown as **extracted text and tables**. The page layout is not
reproduced. Old binary `.doc`, `.xls` and `.ppt` files cannot be opened.
:::

## Permissions

Access to photos and media. Editing a text file writes back to that file.
