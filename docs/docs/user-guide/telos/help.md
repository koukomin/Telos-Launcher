# Help

Telos Help is a built-in app. It teaches the launcher, the Telos apps and a short list of settings.

## Start here

The first screen has three chapters:

1. **The launcher in one minute** — home, search, the app drawer, dock, widgets, gestures and locks.
2. **Telos apps** — a few lines per app and a button that opens that app.
3. **Settings worth changing** — appearance, search, gestures, widgets and System / Shizuku.

Search at the top filters chapters and apps.

## First launch

The first time you use Telos as home, a dialog offers the one-minute tour. **Not now** hides it. **Settings → Home screen → Show Help intro again** brings the dialog back.

## What it does not do

Help does not play a live preview of each app. Each lesson is short text plus **Try it** or **Open** on the real screen.
