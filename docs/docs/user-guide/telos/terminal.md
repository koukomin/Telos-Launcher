# Termux

Telos no longer contains a virtual Terminal, bootstrap downloader or embedded shell.
Install **Termux** from **Store → Recommended → Tools**. This tracks the official
`termux/termux-app` GitHub releases and selects the APK for the device architecture.
The runtime, package management, sessions and updates belong to the separate app.

Super+Enter opens installed Termux. If missing, the shortcut opens its official
source in Telos Store. Keep Termux add-ons from the same distribution/signing
source as the main app; an existing F-Droid installation cannot be updated with a
GitHub-signed APK without resolving the signature mismatch.
