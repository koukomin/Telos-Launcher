# Πρόταση: Telos Media (μουσική, βίντεο, ραδιόφωνο, φωτογραφίες)

Κατάσταση: **πρόταση προς έγκριση**, δεν έχει υλοποιηθεί τίποτα. Ό,τι σημειώνεται «επαληθεύτηκε» το
διάβασα απευθείας στα repos ή στις πηγές. Ό,τι σημειώνεται «να ελεγχθεί» είναι από γενική γνώση και
χρειάζεται επιβεβαίωση πριν βασιστούμε πάνω του.

## 1. Από πού ξεκινάμε σήμερα

Το Telos Radio είναι μικρό (περίπου 700 γραμμές): `RadioPlayerService` (ExoPlayer + MediaSession),
αναζήτηση στο Radio-Browser, αγαπημένα, mini player. Δεν υπάρχει βιβλιοθήκη μουσικής, βίντεο ή φωτογραφιών.

**Τι λείπει σε σχέση με το Transistor** (λίστα από γενική γνώση, **να ελεγχθεί** με το README του Transistor στο
Codeberg, που δεν μπόρεσα να ανοίξω από το περιβάλλον μου):

- προσθήκη σταθμού με δικό σου URL, μετονομασία, αναδιάταξη, διαγραφή
- εισαγωγή και εξαγωγή M3U / PLS, αντίγραφο ασφαλείας της συλλογής
- επίλυση playlist streams (PLS, M3U, HLS) πριν την αναπαραγωγή
- sleep timer
- ICY metadata: τίτλος κομματιού που παίζει, ιστορικό κομματιών, αποθήκευση κομματιού στα αγαπημένα
- εικόνα σταθμού με cache, προσωρινά αρχεία offline
- ειδοποίηση με χειριστήρια, widget, Android Auto, χειρισμός σφαλμάτων και εναλλακτικά streams

Σημείωση: το Transistor στο GitHub είναι πλέον **read-only**, η ανάπτυξη συνεχίζεται στο
[Codeberg](https://codeberg.org/y20k/transistor). Άδεια: MIT (επαληθεύτηκε στο LICENSE.md).

## 3. Αρχιτεκτονική

Ένα νέο ζεύγος modules `:services:media` και `:data:media`, μία Room βάση, μία `MediaLibraryService` (Media3)
για μουσική, βίντεο και ραδιόφωνο, με κοινό mini player.

Το πλεονέκτημα του Telos απέναντι σε οποιαδήποτε άλλη εφαρμογή: είναι **launcher**. Άρα:

- αναζήτηση μέσα στη βιβλιοθήκη από το κεντρικό search bar του launcher (τραγούδια, ταινίες, σταθμοί, φωτογραφίες)
- «τώρα παίζει» στο Dynamic Island και στο lock screen
- widgets, και προσαρμογή στο Desktop Mode (παράθυρα, πολλαπλά πάνελ)

## 4. Features ανά περιοχή

**Μουσική**
- βιβλιοθήκη από την αποθήκευση, άλμπουμ / καλλιτέχνες / είδη / φάκελοι, playlists, gapless, crossfade, ReplayGain
- στίχοι: συγχρονισμένοι (LRC) από το [LRCLIB](https://lrclib.net) (ανοιχτό API χωρίς κλειδί, **να ελεγχθούν** οι όροι)
- επεξεργασία ετικετών (MP3 ID3, FLAC, M4A), εξώφυλλα, μαζική επεξεργασία, εξισωτής, sleep timer

**Βίντεο**
- βιβλιοθήκη ταινιών και σειρών με αναγνώριση από όνομα αρχείου (σεζόν / επεισόδιο), αφίσες, περιγραφές
  και «συνέχισε να βλέπεις»
- **αυτόματη λήψη υποτίτλων** όταν χαρακτηριστεί ένα αρχείο ως ταινία ή σειρά: αναζήτηση με hash αρχείου και
  τίτλο, επιλογή γλώσσας (π.χ. ελληνικά), αποθήκευση δίπλα στο αρχείο
- μηχανή Media3, με εναλλακτική libmpv, gestures, PiP, ταχύτητα, κανάλια ήχου, υπότιτλοι σε πολλές μορφές

**Ραδιόφωνο**
- πλήρης συμπεριφορά Transistor (βλ. §1) πάνω στο Radio-Browser, συν ιστορικό κομματιών

**Φωτογραφίες**
- viewer με χειρονομίες, άλμπουμ, αναζήτηση, χάρτης από GPS
- editor: περικοπή, περιστροφή, φίλτρα, σχεδίαση, κείμενο
- **EXIF**: προβολή, επεξεργασία, αφαίρεση (ειδικά GPS) ανά εικόνα ή μαζικά πριν το διαμοιρασμό

## 5. Σχεδίαση 2026

Material 3 Expressive, δυναμικά χρώματα από την εικόνα του άλμπουμ ή της αφίσας, μετάβαση mini player σε
πλήρη οθόνη, predictive back, edge-to-edge, προσαρμοστικό layout για πτυσσόμενα και Desktop Mode, haptics.
Στο ίδιο visual σύστημα με το Phone app (κοινά components στο `CommsUIUtils`).

## 6. Όροι εξωτερικών υπηρεσιών (σημαντικό)

- **TMDB** (αφίσες και περιγραφές ταινιών και σειρών): δωρεάν για μη εμπορική χρήση με υποχρεωτική αναφορά
  («This product uses the TMDB API but is not endorsed or certified by TMDB»). Προτείνω ο χρήστης να βάζει
  **δικό του API key**, ώστε η διανομή να μην εξαρτάται από ένα κοινό κλειδί.
- **OpenSubtitles**: χρειάζεται API key και λογαριασμό, με περιορισμούς ποσοστώσεων. Προτείνω διεπαφή
  «πάροχος υποτίτλων» ώστε να αλλάζει ο πάροχος χωρίς αλλαγές στο UI. Άλλοι πάροχοι **να ελεγχθούν**.
- Τίποτα δεν στέλνεται αυτόματα: κάθε κλήση σε εξωτερική υπηρεσία είναι επιλογή του χρήστη, σύμφωνα με τη
  φιλοσοφία Secure Dialer (καμία παρακολούθηση).

## 7. Προτεινόμενη σειρά

1. **Radio parity** (μικρό, άμεση αξία): έλλειψη features του Transistor, κοινό `MediaLibraryService`.
2. **Μουσική**: βιβλιοθήκη, player, ετικέτες, στίχοι.
3. **Φωτογραφίες**: viewer, EXIF viewer / remover, μετά editor.
4. **Βίντεο**: player, μετά βιβλιοθήκη σειρών / ταινιών, μετά υπότιτλοι και αφίσες.
5. Ενοποίηση με το search του launcher, το Dynamic Island και τα widgets.

Κάθε βήμα ανεβαίνει ως ξεχωριστό commit, με CI build και δοκιμαστικό APK, όπως και τώρα.

## 8. Ερωτήσεις προς εσένα

- Όνομα: «Telos Media», ή κρατάμε το «Telos Radio» για το tab και φτιάχνουμε νέα ενότητα;
- Σειρά: ξεκινάμε από ραδιόφωνο (προτείνω), ή από βίντεο;
- Είσαι εντάξει να δίνει ο χρήστης δικά του κλειδιά TMDB και υποτίτλων;
- Θέλεις και σύνδεση σε Jellyfin / δικό σου media server;
- Είναι «κρατάμε τα πάντα τοπικά» σταθερή αρχή, ή επιτρέπονται cloud επιλογές;
